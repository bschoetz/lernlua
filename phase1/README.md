# 🎮 Phase 1 — Crafting mit Code

Ein Lua-Crashkurs im Minecraft-Stil. Jede Unit ist eine kleine "Quest" mit Erklärung, Beispiel und einer **Aufgabe zum Ausprobieren**. Am Ende von Phase 1 kannst Du kleine Programme und ein eigenes Mini-Spiel bauen.

> **Vorbereitung:** [Setup](../setup.md) durcharbeiten — VSCodium und Lua müssen laufen.

## Die Units

| Unit | Thema | Neu gelernt |
|------|-------|-------------|
| [1](unit01-hallo-overworld.md) | Hallo Overworld! | `print`, Strings |
| [2](unit02-variablen.md) | Inventar-Slots | Variablen, `..` |
| [3](unit03-rechnen.md) | Rechnen | `+ - * / // ^ %`, `local` |
| [4](unit04-eingaben.md) | Chat mit dem Spieler | `io.read`, `tonumber` |
| [5](unit05-if-else.md) | Türen mit Redstone | `if` / `elseif` / `else` |
| [6](unit06-for-schleifen.md) | Eine Mauer bauen | `for`-Schleifen |
| [7](unit07-while-schleifen.md) | Warten auf den Tag | `while`-Schleifen |
| [8](unit08-funktionen.md) | Eigene Crafting-Rezepte | Funktionen, `return` |
| [9](unit09-tables.md) | Truhen mit vielen Slots | Tables (Listen) |
| [10](unit10-erz-rate-spiel.md) | 🎮 Mega-Projekt | `math.random` + alles zusammen |

## 🏅 Was Du nach Phase 1 kannst

- ✅ Ausgaben mit `print` und Text-Verkettung
- ✅ Variablen anlegen und nutzen (sauber mit `local`)
- ✅ Rechnen mit allen Operatoren
- ✅ Eingaben mit `io.read` und `tonumber`
- ✅ Entscheidungen mit `if` / `elseif` / `else`
- ✅ `for`- und `while`-Schleifen
- ✅ Eigene Funktionen mit Parametern und `return`
- ✅ Tables als Listen
- ✅ Ein komplettes kleines Spiel selbst bauen

➡️ Los geht's mit [Unit 1](unit01-hallo-overworld.md)
